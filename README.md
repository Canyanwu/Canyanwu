## Projects

**[homelab](https://github.com/Canyanwu/homelab)**
A multi node lab built around Proxmox, a Windows Server 2022 domain, TrueNAS storage, a physical Cisco rack (2901, 2960, 3550) and a monitoring stack. Every area has a status, a verification step and a rollback plan, and anything not built yet is marked as planned.

**[homelab-active-directory](https://github.com/Canyanwu/homelab-active-directory)**
Active Directory on Windows Server 2022 with a PowerShell provisioned OU structure and users, and a hardening baseline: SMB and LDAP signing, LLMNR and NetBIOS disabled, LAPS.

**[homelab-network-infrastructure](https://github.com/Canyanwu/-homelab-network-infrastructure)**
VLAN, DNS, DHCP and firewall design for the lab. Planned, with the physical Cisco work already in the main lab.

**[BattleGame](https://github.com/Canyanwu/BattleGame)**
A two player army battle game in Python using inheritance, stack and queue abstract data types, and unit tests.
